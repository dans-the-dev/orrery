Orrery · Robinhood Chain 4663 · ORRY

Launch publik: teknologi inti dan utilitas awal ORRY dulu, sisanya lewat update

Di T0 dibuka inti Orrery: batas belanja agen, pembayaran x402 dalam USDG, cek payer bertanda tangan, dan verifikasi agen. ORRY diluncurkan di Pons di jam yang sama. Begitu ORRY lulus kurva, kontrak ORRY di-deploy: Earn, Stake dan Claim langsung terbuka sebagai utilitas awal, lalu tiga fitur yang sudah jadi dibuka tiap 3 jam. Fitur pasar, chat dan utilitas lain menyusul sebagai update yang memakai titik sambung kontrak yang sudah ada, tanpa mengganti kontrak yang sudah live.

Sisanya tersambung ke titik sambung yang ada atau lewat kontrak baru. Detail di bagian "Update tanpa bertentangan".

Walk pengunjung baru dengan kontrak multi-pair asli lulus: semua fitur tertahan tampil Coming soon, claim dan withdraw tetap jalan, stake terbuka 17 detik setelah dibuka lewat script admin tanpa reload, lalu bisa ditahan lagi. Tinggal digabung ke paket launch.

    Cara kerja saklar rilis
    • Satu tabel releases di Postgres API: fitur ke jam buka (UTC), null berarti ditahan. Diubah lewat satu script admin yang mencatat perubahan.
    • GET /v1/releases publik. Web membacanya tiap menit dan memakai jam server.
    • API menjawab 404 untuk fitur yang belum buka. Web menampilkan "Coming soon" dari satu daftar yang sama untuk nav, halaman ORRY dan docs.
    • Menggeser wave cukup mengubah jamnya. Menarik kembali: set null.
    • Diuji dulu dengan semua wave tertahan, lalu satu wave dibuka di 46630.
  2. T0

    Launch publik: inti Orrery

    LULUS DI 46630 DAN FORK 4663
    • Operator: Safe agen dengan batas per pembayaran, per hari dan float, daftar kontrak yang diizinkan, jeda kenaikan batas minimal 1 jam
    • Agen membayar USDG lewat x402 dari signer-nya sendiri, di dalam batas
    • Signer lookup publik dan halaman agen
    • Credits: pack cek dibayar USDG, API key, cek bertanda tangan EIP-712, SDK
    • Verifikasi agen 5 USDG, masuk ke treasury
    • Docs
    • ORRY diluncurkan owner di Pons dari wallet owner

    Kenapa ini inti: inilah janji tagline, "Let agents pay. Keep spend in range.": operator memasang batas, agen membayar, merchant mengecek. Rehearsal penuh dan walk pengunjung baru lulus di 46630; deploy v1 dan treasury lulus di fork 4663.

  3. Deploy ORRY

    Utilitas awal ORRY

    TERBUKA SAAT DEPLOY
    • Earn: setor ke hub ORRY/ETH dan ORRY/USDG, dapat 85% fee swap
    • Stake: bagian dari pendapatan protokol, dalam ETH dan ORRY

    Kenapa tidak ditahan: ini utilitas awal yang harus ada begitu ORRY beredar, dan Earn hanya butuh hub dan staking. Jamnya ikut kurva Pons: kontrak ORRY butuh harga pool Pons untuk membuka hub.

Aturan tiap wave

15 menit sebelum

  • Indexer tidak tertinggal dari kepala chain
  • Keeper dan relayer punya saldo gas
  • Error RPC dan API di level normal
  • Tidak ada transaksi gagal beruntun di log

Saat jamnya

  • Fitur terbuka sendiri, kartu Coming soon hilang
  • Walk pengunjung baru untuk fitur itu, storage kosong
  • Post X yang sudah dijadwalkan, plus klip 10 sampai 20 detik

Sesudahnya

  • Pantau 30 menit: error console, log API
  • Catat hasilnya di halaman ini
  • Wave berikutnya hanya kalau semuanya hijau

Aturan berhenti: kalau satu cek merah, wave itu digeser, bukan dipaksa. Jamnya diubah lewat saklar rilis dan post X ikut digeser. Fitur yang sudah terbuka tidak ditutup lagi kecuali ia sendiri yang rusak.

Keputusan owner

  1. Jam T0 dan jarak antar wave. Usulan: T0 21.00 WIB, jarak 3 jam.

    21.00 WIB adalah 09.00 di New York, jadi wave ORRY jatuh di jam aktif pengguna Amerika.

  2. Bangun saklar rilis runtime. Usulan: ya, sebelum T0.

    Tanpa saklar, tiap wave butuh restart API dan build ulang web di tengah malam WIB.

  3. Gabung paket launch ORRY ke build/v1 setelah multi-pair dan cek jalur update lulus. Usulan: ya.

    Deploy v1 dan ORRY lalu memakai satu cabang yang sudah dites bersama.

  4. Buat kunci quote signer dan keeper ORRY. Usulan: ya, disimpan di ~/.secrets/orrery/ dan dibackup.

    Tanpa quote signer, checkout ORRY tetap tertutup; tanpa keeper, Distribute dan buyback hanya jalan kalau ada yang memanggil.

  5. Kirim ETH dan ketik CONFIRM untuk deploy v1, lalu deploy ORRY setelah kurva lulus.

    Deploy hanya jalan dengan dana dan CONFIRM dari owner.
